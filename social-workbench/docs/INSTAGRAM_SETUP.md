# Instagram 串接教學（讓系統登入你的 IG 並自動回覆留言）

整體流程：**準備 IG 專業帳號 → 在 Meta 開發者後台建立 App → 把兩個金鑰貼到 Vercel → 在系統按「連結 Instagram」→ 設定關鍵字自動回覆 → 用另一個帳號留言測試**。

約需 20～30 分鐘。

---

## 步驟 1：把 IG 改成「專業帳號」

Instagram 官方 API 只開放給專業帳號（商業或創作者），個人帳號無法串接。

1. 打開 Instagram App →「個人檔案」→ 右上角 ☰ →「設定和隱私」。
2. 找到「帳號類型和工具」→「切換為專業帳號」。
3. 選「創作者」或「商家」都可以，類別隨便選，一路按下一步完成。（免費，之後可以改回來。）

## 步驟 2：在 Meta 開發者後台建立 App

1. 用電腦打開 <https://developers.facebook.com/>，用你的 Facebook 帳號登入。第一次使用要先按「開始使用」註冊成開發者，驗證手機即可。
2. 右上角「我的應用程式」→「建立應用程式」。
3. 填應用程式名稱，例如「社群工作台測試」，然後按下一步。
4. 「使用案例」選 **「管理 Instagram 上的訊息和內容」**（英文為 *Manage messaging & content on Instagram*），然後一路下一步、建立。
5. 進到 App 後，在左邊選單找到「使用案例」→ Instagram 那一項按「自訂」，或直接選「API 設定（使用 Instagram 登入）」。

## 步驟 3：取得金鑰、設定網址、加入測試人員

在「**使用 Instagram 登入的 API 設定**」頁面：

1. **複製兩個值**（頁面最上方）：
   - **Instagram 應用程式編號**（Instagram app ID）
   - **Instagram 應用程式密鑰**（Instagram app secret，要按「顯示」）
   - ⚠️ 注意：要用這個頁面上的「Instagram」編號與密鑰，不是 App 主控板上方的「應用程式編號」（那是 Facebook 的，用了會登入失敗）。
2. **設定重新導向網址**：找到「設定 Instagram 商家登入」（Set up Instagram business login）→「商家登入設定」→「OAuth 重新導向 URI」，貼上：

   ```
   https://你的網址.vercel.app/api/integrations/instagram/callback
   ```

   把「你的網址」換成你的 Vercel 正式網址。系統的「設定 → 社群帳號」頁面也會顯示這個網址，可以直接按「複製」。網址必須一字不差，結尾不要多斜線。然後按儲存。
3. **把你的 IG 加入測試人員**（App 在「開發模式」時，只有測試人員的帳號能登入）：
   1. 左邊選單「應用程式角色」→「角色」→「新增人員」→ 選「**Instagram 測試人員**」→ 輸入你的 IG 帳號名稱 → 送出。
   2. 用手機或電腦登入那個 IG，到 <https://www.instagram.com/accounts/manage_access/>，切到「**測試人員邀請**」分頁 →「接受」。

## 步驟 4：把金鑰設定到 Vercel

1. 打開 Vercel → 你的專案 →「Settings」→「Environment Variables」。
2. 新增以下變數，Environment 三個都勾：

   | 名稱 | 值 |
   |---|---|
   | `INSTAGRAM_APP_ID` | 步驟 3 的 Instagram 應用程式編號 |
   | `INSTAGRAM_APP_SECRET` | 步驟 3 的 Instagram 應用程式密鑰 |
   | `TOKEN_SECRET` | 自己打一串很長的亂碼（用來加密存在資料庫的 IG 權杖） |
   | `INSTAGRAM_WEBHOOK_VERIFY_TOKEN` | （選用）自己取一串字，例如 `my-hook-2026`，步驟 7 會用到 |

3. 到「Deployments」→ 最新一筆右邊「⋯」→「**Redeploy**」。環境變數要重新部署才會生效。

> `TOKEN_SECRET` 設定後就不要再改，改了之後已連結的帳號要重新連結。

## 步驟 5：在系統連結你的 IG

1. 用**正式網址**（跟步驟 3 填的一樣）打開系統，用管理員身分進入。
2. 左邊選單「設定」→「社群帳號」，最上面會有「真實 Instagram 帳號」區塊。
3. 選要連結到哪個品牌 → 按「**連結 Instagram 帳號**」→ 登入你的 IG → 按「允許」。
4. 回到系統後會顯示「已連結 @你的帳號」。系統會匯入你最近 10 篇貼文的現有留言。
   - **連結之前就存在的舊留言不會自動回覆**，避免一連結就對一堆舊留言亂回。

## 步驟 6：設定「業主想要的」自動回覆

1. 左邊選單「AI 與自動化」→「自動回覆」→「新增規則」。
2. 品牌選剛剛連結的那個品牌；觸發方式選「**關鍵字＋固定回覆**」。
3. 關鍵字例如：`價格、多少錢、怎麼買`。
4. 自動回覆內容例如：`{name} 你好～價格與購買方式已經私訊給你囉，請查看訊息 😊`
   - `{name}` 會自動換成留言者的 IG 名稱。
5. 適用平台勾 Instagram（不勾就是全部平台），然後儲存。

安全機制：就算包含關鍵字，客訴、退款、敏感議題、負面情緒、垃圾留言**一律不會自動回覆**，會留在收件匣給人工處理。

## 步驟 7：測試

1. 用**另一個 IG 帳號**（例如朋友的帳號，或你的第二個帳號）到你的貼文底下留言：「請問價格多少？」
   - 用自己的帳號留言不算，系統會把它當成品牌自己的留言而略過。
2. 打開系統的「收件匣」。收件匣開著時約每 45 秒會自動抓一次新留言，也可以到「社群帳號」按「**立即同步**」。
3. 回到 IG 看，那則留言底下就會出現自動回覆 🎉
4. 系統裡那則留言會標示「AI 自動處理」，處理歷程會記錄是哪條規則回的。

### （選用）Webhook：網頁沒開也能即時回覆

前面的做法要有人開著收件匣，系統才會去抓新留言。如果希望有人留言時 Instagram 主動通知系統：

1. 在 Meta「使用 Instagram 登入的 API 設定」→「設定 Webhook」：
   - 回呼網址：`https://你的網址.vercel.app/api/webhooks/instagram`
   - 驗證權杖：填你在 Vercel 設定的 `INSTAGRAM_WEBHOOK_VERIFY_TOKEN`
   - 按「驗證並儲存」，再訂閱 `comments` 欄位。
2. 在同一頁的帳號清單中，把你的 IG 帳號的 Webhook 訂閱打開。

開發模式下，Meta 只會送測試人員帳號的通知；如果 Webhook 沒反應，用前面「收件匣自動同步」的方式也能展示。

## 常見問題

| 狀況 | 原因與解法 |
|---|---|
| 按「連結」後 IG 顯示「Invalid redirect_uri」 | 步驟 3 填的網址跟你現在打開系統的網址不同。請用同一個正式網址，並確認結尾是 `/api/integrations/instagram/callback`。 |
| 「Invalid platform app」或「應用程式無效」 | Vercel 填成了 Facebook 的應用程式編號。請改用「使用 Instagram 登入的 API 設定」頁上的 Instagram 應用程式編號與密鑰，然後 Redeploy。 |
| 登入時說沒有權限，或看不到授權畫面 | IG 還沒接受測試人員邀請（步驟 3 第 3 點），或 IG 不是專業帳號（步驟 1）。 |
| 系統顯示「尚未設定 Instagram 串接」 | Vercel 環境變數沒設好，或設好後沒有 Redeploy。 |
| 留言沒有被自動回覆 | 確認：① 用另一個帳號留言；② 留言是連結**之後**才留的；③ 規則有啟用，且品牌選對；④ 留言不是客訴或負面內容（這類一定轉人工）。可以在「自動回覆 → 測試與模擬」輸入同樣的文字，看系統的判斷說明。 |
| 「Instagram 授權已失效」 | 到「社群帳號」按「連結 Instagram 帳號」重新登入一次。權杖約 60 天，系統會自動延長。 |
| 重設示範資料後 | 已連結的 IG 帳號會保留，不用重新登入，重新匯入的留言也不會再被自動回覆一次。 |

## 技術說明（給老師或開發者）

- 使用 Meta 官方的 *Instagram API with Instagram Login*。權限為 `instagram_business_basic` 與 `instagram_business_manage_comments`，開發模式下測試人員帳號不需 App 審查。
- OAuth 流程：
  1. 用授權碼換取短效權杖，再換長效權杖（60 天）。
  2. 權杖以 AES-256-GCM 加密存在 `account_credentials` 資料表，不會傳到前端。
  3. 剩不到 10 天時自動延長。
- 程式架構：
  - `server/integrations/instagram.ts`：API 呼叫。
  - `server/adapters/instagram.ts`：平台 adapter。已連結的帳號走真實 API，示範帳號走模擬資料。
  - 其他平台（Facebook、YouTube、Google）日後只要新增對應的 adapter，收件匣、自動回覆、紀錄等功能不用改。
- 同步：讀取最近 10 篇貼文與留言（含回覆串）。
  - 已存在的留言略過；品牌帳號自己的留言略過。
  - 連結前的留言不自動處理。
- 自動回覆經過同一套安全檢查。關鍵字規則由業主撰寫回覆內容，不需 AI 知識；但客訴、退款、補償、敏感、無法確認的承諾、高風險與垃圾留言一律轉人工。
